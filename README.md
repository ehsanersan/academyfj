- ⚡ سریع و سبک بدون نیاز به فریم‌ورک

- 🔐 پنل مدیریت برای کنترل محتوا و لیدها

## 🚀 نحوه اجرا

### روش ساده:
1. فایل `index.html` را در مرورگر باز کنید
2. سایت آماده استفاده است!

### با Live Server (پیشنهادی):
1. افزونه **Live Server** را در VS Code نصب کنید
2. روی فایل `index.html` راست‌کلیک کنید
3. گزینه **Open with Live Server** را انتخاب کنید

## 🔌 اتصال به بک‌اند

این نسخه یک نسخه **Front-End Static** است. برای اتصال به بک‌اند:

1. **فرم‌ها**: در `js/forms.js` بخش ارسال فرم را به API متصل کنید
2. **پرداخت**: در `checkout.html` درگاه پرداخت واقعی اضافه کنید
3. **دیتابیس**: داده‌های `js/data.js` را از API دریافت کنید

### نمونه اتصال فرم به API:
```javascript
// در forms.js
fetch('/api/contact', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify(formData)
});
```
